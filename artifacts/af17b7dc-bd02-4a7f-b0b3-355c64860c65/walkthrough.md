# New Features Walkthrough

I have implemented the following features to enhance stock tracking and analysis:

## 1. Refresh All & Comparison History
- **Refresh All Button**: Added a refresh button to the App Bar that updates all active stock sessions at once.
- **Comparison Logic**: When refreshing, the app now compares the new analysis with the previous state.
- **Smart Updates**: Detects and highlights changes in:
    - **Trend Score** (e.g., Score 2 -> 3)
    - **Trend Direction** (e.g., Uptrend -> Downtrend)
    - **Market Structure** (New Higher Highs/Lows)
    - **Trailing Stops** (Only notifies if stop is raised significantly)

## 2. Local Notifications & Event Page
- Integrated `flutter_local_notifications`.
- **Alerts**: When "Refresh All" finds significant changes, a local notification is triggered summarizing the updates (e.g., "AAPL: +HH, TSLA: Score 1->3").
- **Smart Navigation**: Tapping the notification opens the new **Event Log Screen**.
- **Event History**:
    - The **Event Log** stores a history of all major changes.
    - Accessible via the **Notification Icon** in the App Bar or by tapping a notification.
    - Events are persisted across app restarts.

## 3. Data Persistence
- **History Tracking**: `StockSession` now serializes `previousTrendAnalysis` and `previousTrailingStop` to disk. This ensures comparison works even after restarting the app.

## 4. Advanced Event Logic & Background
- **Historical Backfilling**: Events (like "Stop Raised") are now generated by simulating the strategy day-by-day from the Entry Date. This provides a complete history of how the trade would have managed risk.
- **Grouped Event Log**: The Event Log Screen now groups events by Symbol using expandable tiles, making it easier to track specific stocks.
- **Strict Risk Management**: The simulation ensures the Trailing Stop price *never* decreases, adhering to strict profit protection rules.
- **Background Checks**: The app checks for updates periodically in the background (Android/iOS).
    - **Fully Configurable**: Go to the Global Settings dialog to:
        - Enable/Disable background checks.
        - Set active hours (e.g., 9 AM - 5 PM) to save battery.
        - Exclude weekends (Sat/Sun).
        - Set Frequency (e.g., Every 1 hour).

## Usage
1.  **Click the Refresh Icon** in the top-right of the dashboard.
2.  Wait for the process to complete (loading indicators on tabs).
3.  If changes are detected, a system notification will appear.
4.  Tap the notification to view the **Event Log**.
